# AI Assignment Projects

This repository contains two projects:

## Email Filter Agent

A simple reflex agent that classifies incoming messages as email or spam using
allow, restrict domains lists and bad word list rules.

[Read the email filter agent README](email_filter_agent/README.md)

## Three-Jug Water-Measuring Search

A breadth-first search solution to the three-jug problem: use 12-, 8-, and
3-gallon jugs to measure exactly one gallon.

[Read the jug-filling search README](jug_filling_search/README.md)
